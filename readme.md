<h2><br><img src="https://cdn.serilum.com/description/nameplate/about-the-mod.svg" alt="About the mod" width="838" height="64"></h2>
<p><span style="font-size:18px">Biome Spawn Point allows specifying in which biome players should spawn when a new world is generated. This will work for vanilla biomes, as well as modded biomes. Because of the nature of adding biomes via datapacks, you'll have to generate a new world once for the spawnbiomes.txt config file to generate. After that you can select which biomes players should spawn in by removing the exclamation mark in front of the line with the biome name, or with the /bsp enable command.<br><br>The spawn point is placed on land and a bit away from the biome's edge, so a beach that continues into the sea won't leave you in the water. The biome is picked using the world seed, so the same seed gives the same spawn point.<br><br>The bonus chest world generation feature is compatible. If enabled, another bonus chest will be placed around the biome spawn position.<br><br>This mod is compatible with <span style="color:#396;font-size:18px"><a style="color:#396;font-size:18px" href="https://curseforge.com/minecraft/mc-mods/village-spawn-point" rel="nofollow">Village Spawn Point</a></span>. With both installed, players spawn in a village inside the chosen biome, if one can be found nearby.</span></p>

<p>&nbsp;&nbsp;&nbsp;<span style="font-size:18px">All available config options:</span></p>
<div class="spoiler" style="margin-left:10px;padding-left:10px">
<p><span style="font-size:14px"><strong>biomeSearchRadius</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default 6400, min 256, max 30000</span><br><span style="font-size:13px">How far from the center of the world (x=0, z=0), in blocks, the mod searches for one of the spawn biomes. A larger radius finds rarer biomes, but makes creating a new world take longer.</span><br><br><span style="font-size:14px"><strong>minimumDistanceFromBiomeEdge</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default 16, min 0, max 128</span><br><span style="font-size:13px">How far inside the biome, in blocks, the spawn point should be, so players don't spawn just outside of it. When no spot that far inside the biome is found, a spot closer to the edge is used.</span><br><br><span style="font-size:14px"><strong>preferSpawningOnLand</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default true</span><br><span style="font-size:13px">Whether the spawn point should be on land when the chosen biome also exists under water, like beaches that continue into the sea. A spot in water is only used when the biome has no land nearby.</span><br><br></p>
<p><span style="font-size:14px">A config file is generated in <em>./config/serilum/biomespawnpoint/spawnbiomes.txt</em>. By removing an exclamation mark in front of the biome name, it will add a chance for players to spawn in that biome. When one is selected, it has a 100% chance. When two are selected, they each have a 50% chance.</span><strong> <br><br><picture><img src="https://cdn.serilum.com/projects/biome-spawn-point/a.png" alt=""></picture></strong></p>
</div>
<h2><br><br><br><img src="https://cdn.serilum.com/description/nameplate/commands.svg" alt="Commands" width="838" height="64"></h2>
<p><span style="font-size:14px"><em>Both '/biomespawnpoint' and '/bsp' can be used.</em></span><br><br><span style="font-size:14px"><span style="font-size:14px"><em>/bsp usage</em></span> - Shows the usage of commands.</span><br><span style="font-size:14px"><span style="font-size:14px"><em>/bsp reload</em></span> - Reloads all manual changes to the spawnbiomes.txt file.</span><br><span style="font-size:14px"><span style="font-size:14px"><em>/bsp enable &lt;biome&gt;</em></span> - Enables a biome in the spawnbiomes.txt file, so new worlds can spawn in it.</span><br><span style="font-size:14px"><span style="font-size:14px"><em>/bsp disable &lt;biome&gt;</em></span> - Disables a biome in the spawnbiomes.txt file.</span><br><span style="font-size:14px"><span style="font-size:14px"><em>/bsp repick</em></span> - Moves the world spawn point to a random new spot in one of the enabled biomes.</span><br><span style="font-size:14px"><span style="font-size:14px"><em>/bsp reset</em></span> - Moves the world spawn point to where a new world with the same seed would place it.</span></p>
